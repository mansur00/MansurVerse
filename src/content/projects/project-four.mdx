## Overview

An online magazine and research publication built for deep reading, fast content delivery, and expressive editorial typography.

## Problem

Heavy third-party scripts and layout shifts from slow web fonts degraded reading focus, driving bounce rates up on slower connections.

## Solution

Preloaded optimized font subsets, engineered zero-CLS image containers, and leveraged static site generation for sub-second page loads.

## Results

Average reading session duration grew by 30%, while Lighthouse performance scores reached 99 across both desktop and mobile devices.
