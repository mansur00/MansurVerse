## Overview

Generic overview describing Project Four, an international commerce storefront built for fast catalog browsing and seamless purchasing.

## Problem

Legacy monolithic storefront code bloated client bundles to over 2MB, delaying initial checkout interactions on mobile devices.

## Solution

Migrated the catalog to static Astro islands with progressive hydration, localized currency formatting, and zero unused styling.

## Results

Time to interactive dropped to under 1.2 seconds globally, directly driving a 30% measurable improvement in checkout conversions.
