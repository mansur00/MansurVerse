## Overview

An interactive showcase created to demonstrate expressive web typography, magnetic cursor effects, and subtle kinetic motion.

## Problem

Complex motion choreography on experimental sites often compromises low-power device battery life and ignores motion preferences.

## Solution

Structured animations using requestAnimationFrame ticker loops with immediate pause controls and full prefers-reduced-motion compliance.

## Results

Delivered smooth 60fps interactions on modern displays while maintaining full accessibility and keyboard traversability.
