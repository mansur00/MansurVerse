## Overview

A mobile payment application redesign created to simplify peer-to-peer transfers and monthly budgeting for everyday users.

## Problem

Complex form validations and ambiguous confirmation steps led to user frustration, high abandonment rates, and accessibility barriers on screen readers.

## Solution

Built floating label inputs with clear error messaging, implemented optimistic UI updates for transfers, and created tactile micro-interactions that respect reduced motion settings.

## Results

Form completion errors dropped by 50%, while user feedback praised the clear typographic hierarchy and rapid transaction feedback.
