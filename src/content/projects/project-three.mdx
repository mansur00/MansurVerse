## Overview

Generic overview describing Project Three, a brand evolution and component library for a tech startup transitioning into enterprise markets.

## Problem

Marketing teams relied on disconnected templates and arbitrary CSS colors, causing visual fragmentation across digital touchpoints.

## Solution

Defined a single source of truth using semantic design tokens, pixel-stepped geometric shapes, and reusable component primitives.

## Results

Design and engineering handoff times were cut in half, while 100% of brand surfaces now conform to strict WCAG AA contrast rules.
